Isolated publisher tag slot

1. Create a dedicated QA ad unit

In the publisher’s GAM account, create a test-only ad unit such as:

/NETWORK_ID/NEXBID_QA

Do not use a production placement for the first technical checks.

2. Create the QA line item

  • Line-item type: Price Priority
  • Rate: ₹10 CPM, or the agreed QA rate
  • Inventory: only the dedicated QA ad unit
  • Custom targeting: qa=true

3. Add the tag inside a GAM creative

Use the included gam-creative-template.html. Replace the marked test-tag section with the tag under review, then paste the complete creative code into GAM.

<!-- TEST TAG START --> <script src="https://example.com/tag.js"></script> <!-- TEST TAG END -->

4. Request the real GAM slot here

Enter the real ad-unit path in the Live GAM tab, send the request, and verify the event sequence:

slotRequested slotResponseReceived slotRenderEnded slotOnload impressionViewable

5. Correlate the request with a test ID

The page sets qa_test_id. The creative template reads it using the GAM pattern macro:

%%PATTERN:qa_test_id%%

This helps match the page request, GAM creative, tag activity, and exported QA report.

6. Important browser limitation

The page can classify request URLs, event types, response status for observable fetch/XHR calls, and render behavior. It cannot read arbitrary cross-origin response bodies when the remote endpoint does not permit CORS. Use Chrome DevTools or server logs for the full payload.
